This repository contains the new Devil implementation. It is separate from SJ Lite V1.

## Current milestone

Devil Coding Stage 13 — Complete

Stage 13 completed the Constitutional Observation Foundation and integrated the bounded observation-request provider, observation evaluator, result mapper, and unified Observation Authority into the single constitutional runtime path.

The default runtime does not treat execution approval as proof that an action occurred. It does not fabricate observation evidence, verify outcomes, update world state, or report success. Constitutional observation therefore safely defers until a genuine execution-observation source and approved observation policy are available.
